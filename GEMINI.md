## Issue Tracking and Project Management
- **GitHub Project Tracking:** You must keep track of all development and implementation tasks using the GitHub project created for this repository.
- **Meticulous Status Updates:** Whenever you work on a task, you must update the status of the task on the concerned issue in the GitHub repo immediately to reflect its current state.

- **Workflow Enforcement:** Always follow this practice while working on every issue in this GitHub project and repository going forward.
